# Семейный бюджет

Веб-приложение для учёта доходов и расходов семьи. Работает прямо в браузере, не требует установки. Все данные сохраняются локально в `localStorage`.

## ✨ Возможности

- **💰 Учёт доходов и расходов:** Добавление операций с указанием суммы, описания и человека.
- **🏦 Баланс:** Автоматический подсчёт текущего баланса, общего дохода и расхода.
- **📜 История операций:** Удобный список с поиском, фильтрацией (по человеку, типу) и сортировкой.
- **📊 Графики:** Наглядные диаграммы (круговая и столбчатая) с помощью Chart.js.
- **👥 Разделение по людям:** Возможность группировать графики по членам семьи.
- **📥 Экспорт в CSV:** Выгрузка всех операций в таблицу Excel.
- **📝 Заметки:** Встроенный блокнот для планов и напоминаний (сохраняется автоматически).
- **📱 Адаптивность:** Удобно пользоваться как на компьютере, так и на телефоне.

## 🚀 Как запустить

1. Скачайте этот репозиторий.
2. Откройте файл `index.html` в любом современном браузере (Chrome, Firefox, Edge).
3. Готово! Можно вносить доходы и расходы.

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Chart.js](https://www.chartjs.org/) (для графиков, подключается через CDN)
